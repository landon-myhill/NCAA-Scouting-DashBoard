How the Ranking Works

The board is ordered by the strengths model — every number below comes straight from the trained model file, so this page can never disagree with the math.

{% if model %}

Each prospect gets 10 measured strengths (scoring, shooting, playmaking, finishing, rim pressure, rebounding, rim protection, perimeter defense, ball security, size) — every one a percentile within his own draft class at his position, computed from his college stats. The model blends those strengths with an age factor, height, age×skill interaction terms, and a market-validation signal (consensus mock rank — the screen that carries scout intel the box score can't see). All weights are learned from what actually happened to the eligible 2020–23 draft classes (drafted + undrafted who left college, returners excluded), never hand-tuned.

Validation (leave-one-year-out, vs position-relative NBA value): strengths model {{ "%+.3f"|format(model.validation.loyo_spearman_model) }} · legacy formula {{ "%+.3f"|format(model.validation.loyo_spearman_draft_score) }} on the same players. The shipped model is the average of {{ model.bootstraps }} bootstrap fits; every rank carries a 90% confidence band on the board.

Boom/Bust = 1-D logistic calibrations of this model's score (held-out AUC ≈ 0.90 for both), answering "of eligible prospects with this projection, how many became NBA starters / how many washed out."
